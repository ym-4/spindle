Binary Search Trees

A BST is a binary tree where every left child is smaller than the parent and every right child is larger.

Properties
  • Insertion: O(log n)
  • Deletion: O(log n)
  • Search: O(log n)
⭐ Remember: Worst case becomes O(n) if the tree is unbalanced.
