CI/CD Web Application

Express + PostgreSQL, automated tests, WebSocket realtime, and a full CI pipeline — built for demonstration and review.
Project Summary

A backend-first sample application implementing social and collaboration features (users, posts, groups, messaging, marketplace), with production-minded DevOps: migrations, seeding, test automation and GitHub Actions-driven CI.

Key Capabilities
  • Authentication & email verification flows
  • REST API with many resource groups (users, posts, comments, groups, marketplace)
  • WebSocket real-time hub for chat/presence
  • Database migrations + seed scripts (`schema.sql`)
  • Automated tests: unit, integration, end-to-end (Playwright)
How to run locally
npm install
npm run migration:reset
npm run seed   # optional
npm run start
Developer notes

Main app wiring: src/app.js — server bootstrap: src/server.js.

WebSocket hub: src/realtime/wsHub.js. Static demo UI: src/public/.
